# Ada 0.1 product contract

## Core promise

You can write naturally, in fragments or complete sentences. Ada continuously organizes the information into a professional document while leaving the user in control.

## Users

- Doctors
- Lawyers

## Non-negotiables

1. Never invent a fact.
2. User edits are first-class source material.
3. Focused fields are not overwritten.
4. Missing information is surfaced, not guessed.
5. OCR, when added, enters the notes pane after human review.
6. The right pane is editable, not a locked AI answer.

## 0.1 success test

A doctor or lawyer should be able to open Ada, choose their profession, type messy notes, and watch a useful structured draft emerge without learning a prompt format.
